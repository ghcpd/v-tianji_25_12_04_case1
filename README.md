# Enterprise Dashboard

A comprehensive enterprise analytics dashboard application built with React, TypeScript, and modern frontend technologies.

## Features

- **Dashboard**: Real-time metrics and analytics visualization
- **Analytics**: Advanced data analysis with filtering and export capabilities
- **User Management**: Complete CRUD operations for user administration
- **Settings**: Configurable application preferences and user settings
- **Authentication**: Role-based access control with permission management

## Technology Stack

- React 18
- TypeScript
- Vite
- React Router
- Zustand (State Management)
- Recharts (Data Visualization)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Project Structure

src/
├── components/     # Reusable UI components
